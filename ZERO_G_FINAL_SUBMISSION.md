## Short Description

0G Agent Memory Radar turns wallet activity into a persistent AI agent memory brief. It stores the reasoning and proof trail on 0G Storage so future agents and judges can verify the wallet context before taking on-chain actions.

## Long Description

AI agents can generate wallet actions and risk explanations, but those decisions are often temporary and hard to verify later. 0G Agent Memory Radar solves this by converting wallet behavior into an agent-readable memory brief, then attaching a 0G Galileo Storage proof with root hash, transaction hash, and explorer links.

Judges can see the readiness score, generated memory brief, 0G proof trail, and verification links in one recording-safe dashboard. The goal is to make wallet and payment agents safer by giving them persistent, verifiable context before they act.

## 0G Integration

The project integrates 0G Storage by preparing an agent memory JSON payload and attaching a Galileo testnet proof. The demo includes the uploaded memory record root hash, transaction hash, ChainScan link, and StorageScan reference so the proof can be independently verified.
