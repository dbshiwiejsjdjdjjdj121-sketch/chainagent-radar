# QIE Growth Copilot Demo Script

Target length: 90-120 seconds.

## Opening

Hi, this is QIE Growth Copilot, an AI wallet intelligence dashboard for the QIE Blockchain Hackathon.

The problem is simple: Web3 builders can see raw wallet data, but it is hard to decide whether a wallet is active, safe, and ready for the next ecosystem action.

## Demo Flow

First, I open the QIE contest demo. This version is dedicated to QIE, not a generic dashboard.

I paste a QIE testnet wallet address and run the QIE testnet brief. The app checks public QIE RPC data such as balance, transaction count, latest block, and chain ID.

Then the AI brief turns those raw signals into a readiness score, risk level, and recommended growth actions for QIE builders.

Next, the project prepares a QIE proof contract. The generated growth brief is hashed and anchored on QIE testnet through the `QIEGrowthProof` contract, so judges can verify that the demo uses QIE-native infrastructure.

The deployed QIE proof contract is `0xB46D14828d4f20cEFD7fbE69b081b1ffAa94D68F`, and the sample proof transaction is `0xb2cbf45455a9cac4a9843ff6d96ce562204c76a3d622bea64ffdd7261a65bb1d`.

## Closing

QIE Growth Copilot helps QIE ecosystem teams understand wallets, onboard users, and move from raw testnet activity to clear AI-guided growth decisions.

The current hackathon build includes a public repo, live demo, QIE testnet integration, proof-contract workflow, and an honest disclosure of reused components and AI assistance.
