# QIE Growth Copilot Demo Script

Target length: 45-60 seconds.

Live demo: https://chainagent-radar-p9wdvpb0m-yiwangyuai-7161s-projects.vercel.app/?contest=qie

## Short Voiceover

Hi, this is QIE Growth Copilot.

It helps QIE builders turn raw wallet activity into a simple AI growth brief.

I open the QIE demo, keep the sample QIE testnet wallet, and click `Run QIE Brief`.

The app reads QIE Testnet data through the public RPC, including native balance, transaction count, chain ID, and latest block.

Then it summarizes the wallet with a readiness score, risk status, and clear next actions for onboarding or ecosystem growth.

For verifiable proof, this build also includes a `QIEGrowthProof` contract deployed on QIE Testnet. A sample AI brief hash is recorded on-chain, so anyone can inspect the contract, proof transaction, and report hash in the QIE explorer.

QIE Growth Copilot is useful for teams that want a faster way to understand wallet readiness and move users toward the next meaningful action on QIE.

## Show On Screen

1. Open the QIE demo URL.
2. Click `Run QIE Brief`.
3. Show the wallet stats and AI recommendations.
4. Show the proof contract section.
5. Briefly show the GitHub README or submission pack.
