# Disclosure

This project is developed with AI assistance for planning, code generation, writing, and QA.

Open-source references may influence architecture and implementation patterns, but contest-specific submissions should not copy another project as the core product. Generic infrastructure such as React, wallet connection patterns, UI structure, and TypeScript utilities may be reused when contest rules allow it.

Before submitting to a hackathon, create a contest-specific disclosure that lists:

- prior work reused;
- open-source libraries and templates;
- sponsor SDKs and APIs;
- AI assistance;
- new components built during the contest window;
- deployment links and demo video links.
